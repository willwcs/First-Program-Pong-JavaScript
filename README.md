# First-Program-Pong-JavaScript

# 🏓 Pong Game

## 🎯 Objetivo
Recriar o jogo Pong para praticar lógica, eventos e manipulação de canvas/DOM.

## 🛠️ Tecnologias
* **JavaScript** (84.3%)
* **HTML** (11.7%)
* **CSS** (4.0%)
* **Git/GitHub**

## 🧠 O que aprendi
* **Interação e Fluxo de Jogo**: Implementação do controle do estado do jogo, como fazer o botão de inicialização ("Start") funcionar corretamente na interface [1].
* **Mecânicas de Controle de Movimento**: Desenvolvimento e otimização dos controles de movimentação das raquetes, com melhorias específicas aplicadas ao controle do segundo jogador [1].
* **Integração de Tecnologias Front-end**: Estruturação e conexão limpa entre arquivos HTML, folhas de estilo CSS e scripts de comportamento em JavaScript para compor a lógica visual [1, 2].
* **Mapeamento de Backlog e Próximos Passos**: Prática de revisar o código e listar melhorias necessárias em aberto, documentando pendências de desenvolvimento como a criação de um botão de parada ("Stop") e o ajuste de dificuldade do oponente artificial [2].
